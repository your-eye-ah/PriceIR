# PriceIR

**WARNING: This software is currently in active development. Some functions may cause the Flipper Zero to lock up, requiring a hard reset. Use at your own risk.**

## Status
🚧 **Work in Progress** 🚧

This application is designed to interact with Pricer Electronic Shelf Labels (ESL) using the Flipper Zero. It allows for transmitting IR signals to communicate with these tags.

## Features
- **PLID Calculation**: Calculate unique IDs for ESL tags.
- **IR Transmission**: Send commands to graphic and segment ESLs.
- **Android Companion App**: (In Development) A companion app for easier management.
